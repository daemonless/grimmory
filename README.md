Self-hosted digital library — successor to BookLore, with smart shelves, metadata, Kobo/KOReader sync, OPDS support, and a built-in reader.

- **Smart Shelves** — Rule-based filtering, tagging, and full-text search
- **Built-in Reader** — In-browser reading for PDFs, EPUBs, and comics with annotations and progress tracking
- **Metadata Lookup** — Book info from Google Books, Open Library, and Amazon (fully editable)
- **Device Sync** — Kobo compatibility, OPDS support, and KOReader synchronization
- **BookDrop** — Drop files into a watched folder; Grimmory detects, enriches metadata, and queues for review
- **Multi-User** — Individual shelves and preferences with local or OIDC authentication
- **One-Click Sharing** — Send books to Kindle, email, or other users

**Supported formats:** EPUB, MOBI, AZW, AZW3, FB2, PDF, CBZ, CBR, CB7, M4B, M4A, MP3, OPUS

## Deployment

### Podman Compose

**Database.** Where Grimmory keeps its library. The default runs its own MariaDB.

#### Built-in MariaDB (default)

A MariaDB of its own, on the stack's private network.

**1.** Save as `.env` and fill in what is empty:

```env { data-zip-bundle="grimmory-podman" data-zip-filename=".env" }
# Grimmory for FreeBSD (Daemonless)
# Copy to .env and edit.

# Where data lives on the host
DATA_LOCATION=/containers/grimmory/data
EBOOKS_PATH=/containers/grimmory/books
BOOKDROP_PATH=/containers/grimmory/bookdrop
DB_DATA_LOCATION=/containers/grimmory/mariadb

# Database passwords. Change these to random passwords!
DB_PASSWORD=grimmory
DB_ROOT_PASSWORD=grimmory-root

# Timezone (TZ identifier)
# TZ=Etc/UTC
```

**2.** Save as `compose.yaml`:

```yaml { data-zip-bundle="grimmory-podman" data-zip-filename="compose.yaml" }
name: grimmory

services:
  grimmory:
    image: ghcr.io/daemonless/grimmory:latest
    container_name: grimmory
    network_mode: host
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-Etc/UTC}
      - DATABASE_URL=jdbc:mariadb://${MARIADB_HOSTNAME:-127.0.0.1}:${MARIADB_PORT:-3306}/${MARIADB_DATABASE:-grimmory}
      - DATABASE_USERNAME=${MARIADB_USER:-grimmory}
      - DATABASE_PASSWORD=${DB_PASSWORD}
      - SWAGGER_ENABLED=false
      - FORCE_DISABLE_OIDC=false
    volumes:
      - ${DATA_LOCATION}:/app/data
      - ${EBOOKS_PATH}:/books
      - ${BOOKDROP_PATH}:/bookdrop
    depends_on:
      - mariadb
    restart: unless-stopped

  mariadb:
    image: ghcr.io/daemonless/mariadb:latest
    container_name: grimmory-mariadb
    network_mode: host
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-Etc/UTC}
      - MYSQL_ROOT_PASSWORD=${DB_ROOT_PASSWORD}
      - MYSQL_DATABASE=grimmory
      - MYSQL_USER=grimmory
      - MYSQL_PASSWORD=${DB_PASSWORD}
    volumes:
      - ${DB_DATA_LOCATION}:/config
    restart: unless-stopped
```

Then run `podman-compose up -d`.

## Parameters

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PUID` | `1000` |  |
| `PGID` | `1000` |  |
| `TZ` | `Etc/UTC` | Timezone |
| `DATABASE_URL` | `jdbc:mariadb://${MARIADB_HOSTNAME:-127.0.0.1}:${MARIADB_PORT:-3306}/${MARIADB_DATABASE:-grimmory}` | MariaDB JDBC URL (e.g., jdbc:mariadb://127.0.0.1:3306/grimmory) |
| `DATABASE_USERNAME` | `grimmory` | Database username |
| `DATABASE_PASSWORD` | `grimmory` | Database password |

| `FORCE_DISABLE_OIDC` | `false` | Force-disable OIDC authentication (default: false) |
| `DATA_LOCATION` | `/containers/grimmory/data` | Path to store Grimmory configuration and application data |
| `EBOOKS_PATH` | `/containers/grimmory/books` | Path to your ebook library |
| `BOOKDROP_PATH` | `/containers/grimmory/bookdrop` | Drop folder watched for automatic imports |
| `DB_DATA_LOCATION` | `/containers/grimmory/mariadb` | Path to store MariaDB data files |
| `MARIADB_HOSTNAME` | `` | Where Grimmory finds MariaDB (fjord sets this for the built-in one; 127.0.0.1 on host networking) |
| `MARIADB_PORT` | `` | MariaDB port (your own MariaDB) |
| `MARIADB_DATABASE` | `` | Database name (your own MariaDB) |
| `MARIADB_USER` | `` | Database user (your own MariaDB) |
| `DB_PASSWORD` | `grimmory` | Database password (grimmory user) |
| `DB_ROOT_PASSWORD` | `grimmory-root` | MariaDB root password (built-in MariaDB only) |
| `JAVA_TOOL_OPTIONS` | `` | Additional JVM options (e.g., -Xmx256m) |
